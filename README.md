# 我ai学习（StudyOS）· 本地化备考工作台

专为 **2026 考研专硕 095131 农艺与种业（作物方向）** 打造的备考工作台：207 个知识点、90 天计划、艾宾浩斯自动复习、闯关打卡、错题本、AI 讲题提示词。

**0 成本 · 本地化运行**：纯静态网页，数据全部存在浏览器本地（localStorage），零账号、零上传、零服务器费用、断网可学。

---

## 一、怎么用（三选一）

### 方式 A：直接双击打开（最简单）

双击 `app.html` 即可使用全部核心功能（打卡、闯关、复习、积分、备份）。

> 局限：直接以 `file://` 打开时，浏览器会禁用 Service Worker，因此「添加到主屏幕」「离线缓存更新」不可用。数据仍正常保存在本地。

### 方式 B：本地服务（推荐，体验完整）

双击 `启动-本地服务.bat`，浏览器会自动打开 `http://127.0.0.1:8080/`。

要求：电脑已安装 [Node.js](https://nodejs.org/)（任何较新版本均可，无需安装任何依赖包）。

在本地服务下：

- PWA 可正常注册，「添加到主屏幕」后像 App 一样全屏使用；
- 断网后仍可打开（Service Worker 已缓存）；
- 手机与电脑同一局域网时，可把 `127.0.0.1` 换成电脑局域网 IP 在手机上访问。

关闭启动窗口即停止服务，学习数据不丢失（保存在浏览器里）。

### 方式 C：部署到免费静态托管（可选，仍是 0 成本）

项目是纯静态文件，可直接拖到 Cloudflare Pages / GitHub Pages / Vercel 等免费托管。仓库已附带 `_headers`（CSP 安全策略）与 `sw.js`、`manifest.webmanifest`，原样上传即可。

## 三、数据安全

- 所有进度、积分、错题保存在**当前浏览器**的 localStorage，不上传任何服务器；
- 「我的 → 数据管理 → 导出」可下载 JSON 备份；换设备后「导入」即恢复；
- 导入前应用会自动把当前数据备份到 `wb_kaoyan2_preImportBackup`，覆盖后仍可找回；
- 「清空」需二次确认，且清空后从当天开始新一轮 90 天计划。
